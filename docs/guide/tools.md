# 工具与设置

## 设置分类与帮助

设置首页分为语言与外观、悬浮球与手势、截图与相册、查找与高亮、信息本与输入、宏与无障碍、终端日志、权限与系统入口。点击选项左侧的 ⓘ 可打开详细说明，含影响、适用情形和示例；长按可查看系统工具提示。数值项还列出范围和默认值。

悬浮布局编辑器与运行时共用半圆位置：从上到下五个球，中心表示双击功能。支持同一动作绑定到多个位置，也可将位置设为不执行。点击“应用悬浮布局”可立即更新球尺寸与透明度。

长截图默认开启“自动保存到相册”，每张分图写入 `Pictures/GAndroidTools`。Android 10 及以上通过 MediaStore 发布，不申请相册读取权限；Android 8/9 在启用时需要存储写入授权。关闭自动保存只保留应用内导出；相册写入失败也会保留应用内文件并报告保存张数。相册副本与应用内副本分别管理，删除其中一个不会自动删除另一个。

## 超级后台

从悬浮球触发“移入隐藏屏幕”会直接移动当前主屏前台焦点应用，不弹出选择列表；在软件内部使用“选择运行中任务”时会展示应用标题供选择。任务移到公开虚拟屏幕后，每个隐藏任务保留独立的渲染 Surface，最多四个隐藏屏幕；任务移屏需要 Android 11 及以上。打开 **后台任务视图**，点击卡片将其移回主屏并取得焦点。悬浮服务运行期间会轮询任务状态；如果系统最近任务界面已将任务移回主屏，下一次轮询会释放对应隐藏屏幕。部分桌面不能跨屏恢复任务，此时使用工具箱卡片恢复。应用不接管系统最近任务界面。停止悬浮服务时会尝试恢复已跟踪的任务并释放屏幕。

## 单张截图与延迟转盘

选择 **截图（冻结后编辑）** 会先获取屏幕像素并紧接着保存控件树，再打开全屏覆盖编辑页。编辑期间只使用内存中的这次快照，不继续读取目标页面。可直接点击预览切换最小控件的显示，也可在带复选框的冻结控件树中批量选择；支持控件轮廓预览。隐藏区域保留为透明像素，导出页面包时清空隐藏控件的文本与描述，不附带原始未遮挡图片。关闭编辑页释放原始快照内存。

点击截图动作使用默认延迟；长按菜单中的截图动作，或长按悬浮球拖到截图选项后释放，会显示二级延迟转盘，支持 0、1、3、5、10 秒及自定义延迟。倒计时显示在悬浮球中，**取消延迟截图** 可以停止等待。

设置中可选择悬浮球的双击动作，默认是单张截图，也可设为不执行。单击在设定的双击窗口结束后打开菜单，避免与双击同时触发；长按时间也可调整。

## 超级长截图

启动会话后，使用 **＋** 采集一帧，**▶** 自动采集，**✓** 导出，**⇅** 切换模式，**▣** 打开控件树，**⚙** 快捷设置，**×** 取消。暂停会停止自动采集并保留已有帧。

- 跳屏模式优先请求可访问容器向前滚动，失败时使用接近一屏的手势。
- 滑动模式执行可设置时长的手势，并等待页面渲染。
- 手动模式只采集主动请求的帧，由你滚动目标应用。
- 截图控件区域取所有勾选控件边界的并集；没有选择时截全屏。
- 忽略控件会在每帧中按实际位置透明挖空。
- 顶部与底部裁剪可以去掉固定栏；空区域会报错。
- 帧暂存到缓存目录，导出时通过采样像素寻找重叠。没有可靠匹配时另起一张图，不强行拼接。支持帧数、单图高度、PNG/JPEG 和 JPEG 质量设置。

## 超级查找

搜索控件文本和描述。找到后请求 `ACTION_SHOW_ON_SCREEN`，刷新边界并显示不接收触摸的短暂高亮。未找到时，在设置次数内滚动可访问容器。搜索从当前位置开始，无法检索目标应用尚未暴露的数据。

## 无障碍管理

通过 Shizuku 读取已安装服务并调整当前安卓用户的无障碍设置，保留其他已启用服务。保持开关会在指定服务从启用列表中消失时重新开启，不能作为通用崩溃检测器。保持需要悬浮服务运行、Shizuku 持续连接及系统允许修改设置。主动关闭服务会同步取消保持。

## 信息本

分类可多层嵌套，界面不设置固定深度限制。每页读取 100 个条目，支持标题搜索和分页。点击信息填写，长按卡片查看或删除。支持添加隐私文本和导入 `otpauth://totp` URI。动态码支持 SHA1/SHA256/SHA512、6 或 8 位和 5～120 秒周期，实时刷新并显示倒计时。每次生物识别后，隐私内容最多显示 30 秒。选择条目会关闭面板并在设定时间内等待可编辑输入框，排除密码框。

## 日志

终端支持模块或消息关键词筛选、日志级别筛选、暂停和自动滚动。磁盘日志每 2 MiB 轮转，保留一份上次文件，导出包含两份内容。正常操作日志不记录输入值、OTP URI 或脚本正文。导出文件通过安卓系统分享保存。

## 控件树与轮廓选择

单张截图和长截图控件规则共用先截图、后选控件的冻结预览。点击选择最小控件，长按位置可列出附近全部控件复选框。控件树使用独立不透明背景，支持展开／收起层级、可读标题和常见控件类型的中文说明；目标应用文字和未知类型、资源 ID 保留原文。

长截图支持切换保留与忽略规则，预览选区并应用到后续采集帧。保留区域取并集，未选择保留控件时截全屏。隐藏／忽略区域导出为 PNG 透明像素，不能恢复已合成截图中被遮挡的内容。透明遮罩会自动保留 PNG，即使设置选择 JPEG。控件树不可用而存在控件规则时停止采集，防止漏掉遮罩。

## 自动更新

首页“检查更新”可手动检查；设置 → 语言与外观可配置自动检查和间隔小时数（默认 24）。在打开应用时按间隔检查，不常驻后台轮询。下载需要确认，显示进度并可取消；校验 SHA-256、文件大小、包名、递增版本与原签名后，由安卓进行安装授权和确认。应用不内置 GitHub Token。

## 冻结图层与滚动历史

普通“保存截图”默认也会生成 `.gatpage`，保留冻结合成图、有限大小的控件树、能获取的独立窗口图像与控件裁剪片段。窗口图像需要 Android 14+ 和已启用的控件兼容通道；安全窗口、不可用或超预算窗口会标明原因，不会绕过保护。控件片段明确标记为合成图裁剪，不能恢复同一窗口内部被遮挡的内容。主截图和窗口回调不是原子的同一帧，图层包记录各自捕获时间和时间跨度。

长截图可先采用可靠对齐的主应用窗口图像，避免其他窗口的浮层。随后测量正文滚动位移，识别固定边缘：每组可靠对齐的画面仅在开头保留一次顶栏、末尾保留一次底栏。正文中的静止控件会被遮罩；可从其他帧在同一页面坐标真实拍到、且未被遮挡或忽略的像素补全。未观察到的部分保留透明。位移有歧义时分图，不按猜测删除正文。仍可使用手动裁边和忽略控件规则。

可选 `.gatlong` 历史包保留已处理帧、脱敏控件／窗口元数据、对齐位移、固定范围及补全统计；不包含未遮罩原图或单独的原始窗口缓冲图像。参考帧数量与采集磁盘空间均有上限，相关高级选项在“设置 → 截图与相册”。
