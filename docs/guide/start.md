# 快速开始

## 运行要求

Android 8.0 及以上、Shizuku API 13，以及通过 ADB 或 root 启动的 Shizuku 服务。部分系统隐藏接口是否可用取决于设备固件。

1. 从 Releases 安装 APK。质量检查通过后发布预览版，正式版由手动发布触发。
2. 启动 Shizuku，在首页选择 **连接 / 授权 Shizuku**。
3. 授予 **显示在其他应用上层** 权限，开启悬浮工具。常驻通知提供停止入口。
4. 切到目标应用，长按悬浮球，再拖向所需功能并释放。
5. 录制控件操作时，在系统无障碍设置中启用 **GAndroidTools · 输入与宏录制**。信息填写可以使用此桥接或 Shizuku 自动化。

## 悬浮窗手势

悬浮球靠左时，五个功能球沿右侧半圆展开；靠右时镜像到左侧。长按到达判定时间后拖向对应方向，释放触发。先单击一次，再按住拖动可移动悬浮球，直接短拖不会移动。双击执行中心绑定的动作。

在 **设置 → 悬浮球与手势** 点击预览中的外球分配固定位置，点击中心球设置双击。左右预览只展示镜像效果；运行时按球所在屏幕侧边自动选择方向。自动贴边设为 0 可关闭，立即贴边动作始终可用。

## 隐私

截图和脚本可能包含其他应用中的信息，分享前请检查。控件元数据和录制排除密码字段文本，但截图像素仍可能包含敏感信息。隐私信息需强生物识别验证；更改已录入的生物识别可能使加密密钥失效。卸载应用会删除本地数据和密钥。
