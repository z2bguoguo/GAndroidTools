# Contributing / 贡献指南

Read AGENTS.md for the source map, validation commands and platform boundaries. Keep changes focused and update both documentation languages. Behavior changes need meaningful tests; system-dependent features must include reproducible device evidence before their compatibility status is expanded.

Run formatting, unit tests, lint, APK build, repository checks and VitePress build before submitting. Do not add private test exports or signing material. Public documentation describes product behavior and compatibility.

修改前请阅读 AGENTS.md。保持中英文文档同步，为行为变化提供有效测试；系统相关能力需有可复现的真机证据。提交前运行格式、测试、Lint、APK、仓库与文档检查。
